# Judge walkthrough and video script

## Fast interactive demonstration

Open Today through the landing CTA. Keep **Verified Run** selected. Its labels explicitly say authentic historical replay. Choose PSX **Correct & teach**, keep the example correction, review the model-derived structured rule, and save it. Separately approve PSX. Run the next event. VLO's consideration note is prepared under the approved rule with verified database readback. The summary shows one repeat decision avoided.

Open the investigation to see primary issuer evidence, authorized preserved Alpaca bars, independent Research and blind Challenge summaries, exact source quotations, deterministic policies and note hash. Preferences shows application count, scope, expiry and pause/edit/revoke controls. Activity shows the durable audit.

Switch to **Live Nemotron** to request new inference over that preserved evidence. Results and latency can differ; a fresh hold is truthful. Switch to **Autonomous** to inspect actual worker progress for the last completed exchange session. Failures and queued work remain visible; they are not counted as completed actions.
