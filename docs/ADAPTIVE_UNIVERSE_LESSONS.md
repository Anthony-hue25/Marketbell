# Adaptive Universe → MarketBell: engineering lessons transferred

Adaptive Universe (`C:\Users\antho\adaptive-universe-lab`, HEAD `ef76b6c`, 10 commits) was inspected **read-only**: its
docs (`docs/FORWARD_DATA_MODEL.md`, `docs/ENGINEERING_AUDIT.md`, `docs/RESEARCH_V2.md`, `docs/HISTORIAN.md`,
`SECURITY.md`) and the commits that record actual defects and corrections (`ef76b6c` decision-time evidence,
`1247078` rolling-window false revision block). Nothing in that repository was modified. Trading algorithms
were not transplanted; only the integrity patterns were mapped.

Every MarketBell defect below was **reproduced against the pre-assurance code** with
`scripts/assurance_repro.py` (same script, run unchanged on the snapshot and on the current code; output in
`docs/evidence/ASSURANCE_REPRODUCTION.json`) and is covered by a regression test in `test/test_assurance.py`.

## What was deliberately *not* transplanted

- Adaptive Universe's quant quality score, universe rotation and governor checks are trading-specific.
- Research V2's multi-search breadth rule (two topic classes) depends on tool-driven retrieval that MarketBell
  does not have; MarketBell's analogue is the substantive-evidence gate (row 6).
- The Excel historian: MarketBell's equivalent derived view is the Impact/Learning Journal over immutable tables.


## Second transfer (2026-10-21): the Quant + Nemotron run-time audit

The Adaptive Universe run-time audit (Oct 21 close cycle: ~48 min, of which ~5 min AI) found repeated
integrity work, per-item reloads, research on candidates that could not be used, no early stop, silent
configuration gaps and stale special cases. MarketBell was audited for the same classes of defect.
Regression tests: `test/test_build_lessons.py` (21 tests).

| Quant lesson | MarketBell finding | Fix |
|---|---|---|
| T1/F7 verify once, not per read | Start-up journal verification searched the whole joined journal once per case: quadratic (2,000 cases 0.59 s, 4,000 ≈ 2.3 s, a year tens of seconds), paid on every API start and every scheduled worker run | Commitments collected once as a set: 4,000 cases 0.56 s, linear |
| T3/T8 parse once | Preserved price download (~150k rows) re-read and filtered per symbol per case | Parsed once per file size/mtime, 30-row tail per symbol kept |

| T4 do not research what cannot be used | Discovery rotation included mandate-excluded stocks (research could never promote them).
